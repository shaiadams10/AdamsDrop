# Artwork

The project owner supplied the icon artwork and README banner.

`icon.png` is a square crop of the original icon artwork, sized to 1024 pixels.
`windows-client/tray_icon.ico` contains 16, 20, 24, 32, 40, 48, 64, 128 and 256 pixel
representations for Windows tray, Explorer and application resources.
The build embeds that ICO in AdamsDrop.exe and also installs it beside the app.

`readme-banner.png` preserves the supplied banner's pixels. Its depicted devices
are illustrative: see the README for the tested workflows and platform limits.
Image metadata was omitted from the repository exports.
